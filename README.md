# Reality Creationz – Fresh Masculine Candle Collections

This repository contains a single-page marketing site for Reality Creationz candles. The experience showcases the signature fresh masculine core line, rotating seasonal releases, the brand story, and customer feedback.

## Getting started

Open `index.html` in any modern browser, or serve the repository locally:

```bash
python3 -m http.server
```

Then visit <http://localhost:8000>.

## Project structure

- `index.html` – Main landing page markup
- `styles.css` – Global styling for layout, typography, and theme
- `script.js` – Enhancements for smooth scrolling and dynamic copyright year

All imagery is sourced from Unsplash and referenced via direct URLs.
